Place the latest cumulative IVA Excel release in this folder.

Example:
  IVA_July_2026.xlsx

The Python script scans all .xlsx files here and automatically chooses the
workbook that contains the latest 2026 month. Because the VBoS IVA workbook is
cumulative, that single latest workbook is used to regenerate January through
the latest available month.

IMPORTANT: This GitHub repository is public. Only store an Excel release here
if it is approved for public access.
